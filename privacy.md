# Privacy Policy for Valora PR Bot
**Effective Date:** 01/11/2026 (DD/MM/YYYY)  

## 1. Information We Collect
To provide Roblox group integration, server point management, and moderation functions inside Valora Stores PR Hub, Valora PR Bot processes and securely stores the following specific data points:
* **Discord Identifiers:** Your Discord User ID, username, and interaction timestamps.
* **Roblox Identifiers:** Stored Roblox User IDs linked to your Discord account for account verification and group rank syncing.
* **Roblox Group Data:** Group rank titles and rank IDs associated with your linked Roblox account.
* **Custom Server Data:** User point balances, activity metrics, and custom values earned inside the server.
* **Moderation History:** Server warning logs, mute history, kick/ban records, and staff notes associated with your Discord User ID.

## 2. How Your Data Is Used
We process and store this data strictly to:
* Verify Roblox account ownership and automate group rank management.
* Maintain and display server point leaderboards and user statistics.
* Keep persistent moderation logs for server safety and administration.

We **never** sell, rent, monetize, or trade your data to any third parties.

## 3. Data Storage & Security
All stored data (including database files, linked accounts, and moderation records) is kept private and stored securely on private server infrastructure. No user data, database backups, or configuration files are made publicly accessible or stored in public repositories.

## 4. Third-Party API Integrations
The Bot communicates strictly with official third-party APIs to deliver its services:
* **Discord API:** To handle commands, messages, and server permissions.
* **Roblox API:** To fetch account details and check/update group ranks.

## 5. Data Retention & Deletion Rights
Under Discord's Developer Policy, you have the right to request access to or deletion of your stored data.

* **Retention:** Stored data is retained for as long as you remain a member of [Server Name] or until deleted by a server developer/administrator.
* **Deletion Requests:** You can request that your linked Roblox ID, custom point balances, or profile data be permanently deleted by opening a support ticket in Valora Stores PR Hub or emailing `smithw11@valora.firxd.me`.
* *Note: Active server moderation history may be retained where necessary to maintain server safety and enforce rules.*
